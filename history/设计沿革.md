## 本轮决定

- 延续浅牛皮纸 + 蓝色 + 橘色；个人主页署名使用已确认 GitHub 身份 HoshitoXiusun。
- 共享播放器和右侧截图集，但不依赖工作台运行时。
- 手动捕获不更改 pause 状态，仍提供明确的暂停选项；时刻与像素在同一同步 canvas drawImage 操作时记录。
- 批量取帧需要临时 seek，结束后恢复旧位置，之前正在播放时继续播放。
- 默认声音开启，音量 80%。导出使用源音轨样本，不套用静音、音量或播放速度。
- 保留旧 .lawdesk 项目兼容，标准入口为 index.html；离线下载重建干净 HTML 与原始脚本，不复制当前 DOM 中用户的素材或备注。
- 视频 / 音频 / 截图在本机处理，不引入 CDN、分析、账号或上传接口。GitHub 托管公开程序文件。
