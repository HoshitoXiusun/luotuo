## 本轮决定

- 延续浅牛皮纸 + 蓝色 + 橘色；个人主页署名使用已确认 GitHub 身份 HoshitoXiusun。
- 共享播放器和右侧截图集，但不依赖工作台运行时。
- 手动捕获不更改 pause 状态，仍提供明确的暂停选项；时刻与像素在同一同步 canvas drawImage 操作时记录。
- 批量取帧需要临时 seek，结束后恢复旧位置，之前正在播放时继续播放。
- 默认声音开启，音量 80%。导出使用源音轨样本，不套用静音、音量或播放速度。
- 保留旧 .lawdesk 项目兼容，标准入口为 index.html；离线下载重建干净 HTML 与原始脚本，不复制当前 DOM 中用户的素材或备注。
- 视频 / 音频 / 截图在本机处理，不引入 CDN、分析、账号或上传接口。GitHub 托管公开程序文件。

## v1.0.1 · 播放体验修复（2026-10-09）

- 问题：普通定位统一执行 pause，时间轴拖拽后停止；快捷键复用单帧步进；零音量解除静音仍无声、调高音量仍可能保持静音，界面音量与实际媒体音量可能不同步。
- 改进：普通定位不调用 pause；播放时定位继续播放，暂停时定位仍暂停；保留单帧暂停行为。拖拽预览期间不被 timeupdate 抢回原进度。
- 左右键每次 3 秒，播放按钮仍获焦时也可用；时间轴获焦时同样使用 3 秒，其他输入区保持其编辑行为。
- 声音：新文件恢复非静音及 80% 音量；完整同步滑条、百分比与实际状态；调高音量解除静音，零音量解除静音恢复最后有效音量；启用可用音轨，增加“恢复声音”按钮。
- 保留本地处理与可选时间戳，无远程依赖；原工作台工程与 v1.0.0 历史不覆盖。
