帧律 FrameRight

离线使用
用当前版本的 Chrome、Edge、Firefox 或 Zen 打开离线 HTML，选择本地视频即可使用。
视频解码及部分音视频导出格式由浏览器提供。源视频、截图和备注在本机处理。

在线部署
将静态部署包中的 index.html 上传到你选择的静态网站服务，设置为网站首页，并启用 HTTPS。
可以使用已有的国内对象存储静态网站或 Web 服务器，按服务商说明完成设置。
程序的脚本、样式、系统字体回退和 PDF 库均随单文件提供，运行无需额外 CDN 或 API。
网络访问效果由所选托管服务、域名和用户网络决定，部署后应从目标网络实测。

更新
用新版 HTML 替换旧文件。关闭页面前保存截图项目，重新打开后可继续导入 .lawdesk 文件。
页面的「关于与开源许可」包含第三方许可证。
