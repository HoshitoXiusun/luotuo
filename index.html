帧记 · 使用指南

  1. 选择或拖入本地视频，点击播放。默认开启声音，静音和音量控制位于播放器下方。
  2. 手动截取会保留播放器当前状态：播放中继续播放，暂停时保持暂停。可勾选「截图后暂停播放」逐帧复核。截图保留在右侧，可预览、备注、删除及撤销。
  3. 空格播放 / 暂停，← / → 按设定帧率定位，Enter 截图，M 切换静音；输入框和按钮有焦点时不触发快捷键。
  4. 范围批量截取支持时间 / 帧范围，起止留空处理全片。批量时临时暂停并定位画面，结束后恢复之前的播放位置与播放状态。帧号按填写的 FPS 换算。
  5. 水印设置可选择添加或不添加时间戳；每张截图还能单独覆盖全局设置。可导出 PNG / JPG / WebP，或带 CSV 与元数据的 ZIP。
  6. 音频工具支持音轨 WAV 导出，起止留空导出整段；试听音量 / 静音 / 速度不会改变导出音频。音轨导出限 5 分钟、100MB 内的单 / 双声道源视频，解码能力取决于浏览器。
  7. 保存截图项目后可继续编辑。兼容之前工作台的 .lawdesk 视频项目；项目不包含原视频，恢复后需重新选择。
  8. 「离线页面」可下载当前单文件 index.html，之后用 Chrome / Edge 打开即可断网使用。关闭前请保存截图项目。

关于帧记

HoshitoXiusun 的个人视频截图与音轨工具，v1.0.0。源自本地视频工具与律师工作台的视频模块，独立运行，不需要工作台或 PDF 引擎。截图流程参考 FrameWow，路径工具与视频 SVG 图标源自 Docsy。

文件只在浏览器本地处理。页面无账号、广告、分析脚本或上传接口。
